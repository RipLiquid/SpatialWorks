# Map Projections

This section compares four projected coordinate systems and the distortions they introduce when representing the world on a flat surface.

## Maps

- `sinusoidal.png` — World Sinusoidal, an equal-area pseudocylindrical projection.
- `pseudo-mercator.png` — WGS 84 / Pseudo-Mercator, which preserves local shape but strongly distorts area at high latitudes.
- `equidistant-cylindrical.png` — Equidistant Cylindrical, preserving selected distance relationships.
- `van-der-grinten.png` — Van der Grinten I, a compromise projection.

## Skills Demonstrated

- Coordinate reference systems (CRS)
- Projection selection
- Area, shape, distance, and direction distortion
- Tissot indicatrix interpretation
- Matching a projection to the analytical purpose of a map
