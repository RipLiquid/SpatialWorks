# Proportional-Symbol Mapping

These maps use proportional symbols to represent population totals at several geographic scales using 2016 Canadian census geography.

## Maps

- Population aged 65+ by province, Canada
- Population aged 65+ by census division, Ontario
- Population aged 65+ by census subdivision, Toronto CMA
- Population aged 0–14 by census division, Ontario

## Skills Demonstrated

- Proportional-symbol design
- Mapping counts and totals appropriately
- Census divisions and subdivisions
- Multi-scale cartography
- Visual comparison of demographic distributions
