# Field GIS and ArcGIS Online

A campus coffee-shop census was collected with ArcGIS Survey123 and then explored in ArcGIS Online.

## Field Collection

Survey123 was used on a mobile device to capture location and attribute information. The exercise introduced practical data-quality considerations including positional accuracy, missing values, duplicate observations, inconsistent attributes, and the limits of manual collection.

## ArcGIS Online Analysis

The resulting hosted feature data was visualized and filtered in ArcGIS Online. Work included:

- proportional-symbol mapping of coffee prices;
- labels and feature filtering;
- interactive hosted layers;
- descriptive exploration; and
- creation of a derived "Best Value" measure using atmosphere rating and coffee price.

## Skills Demonstrated

- ArcGIS Survey123
- Mobile GPS data collection
- Attribute collection
- ArcGIS Online
- Hosted feature layers
- Filtering and labeling
- Derived metrics
- Data-quality assessment
