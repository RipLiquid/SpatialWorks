# Interactive Web Mapping

This section demonstrates the transition from static desktop cartography to interactive web maps.

## Global Life Expectancy

The life-expectancy map included layer controls, feature popups, hover highlighting, zoom navigation, and multiple attributes exposed through interactive popups.

## Scale-Dependent Municipal Mapping

A municipal web map used scale-dependent visibility to control the amount of detail shown at different zoom levels:

- city scale — municipal boundary and major roads;
- neighbourhood scale — additional roads, parks, and trails;
- street scale — all relevant layers visible.

A query expression was used to restrict the road layer to major roads and highways at broader scales.

## Skills Demonstrated

- Interactive web cartography
- Popups and hover highlighting
- Layer toggles
- Scale-dependent rendering
- Query-based filtering
- Map usability and performance trade-offs
