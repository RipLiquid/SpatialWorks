# Vector Mapping and Data Integration

## Victoria Park Tree Inventory

A QGIS map of street trees in the Victoria Park Heritage District. The source inventory contains point features with tree attributes such as species and diameter at breast height (DBH). The workflow included attribute-table inspection, expression-based filtering, vector symbology, and layout design.

## Toronto Homicides and Historical Census Geography

A multi-source QGIS composition integrating:

- Toronto homicide point locations, 1990–2014;
- 1961 Census of Canada census tracts;
- Great Lakes bathymetry contours; and
- a web basemap for geographic context.

This exercise focused on discovering, combining, and documenting spatial data from different providers.

## Skills Demonstrated

- Point and polygon vector layers
- Attribute filtering
- Multi-source data integration
- Historical census geography
- Basemap integration
- Cartographic layout design
